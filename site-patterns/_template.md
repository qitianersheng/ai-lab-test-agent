# 站点经验：{{PROJECT_NAME}}

本文件沉淀 {{PROJECT_NAME}} 项目的**已验证事实**，作为 3 步流程的长期记忆：
- **Step 1 测试用例设计** 优先读，复用项目内已知事实，避免用例与现状脱节

**写入约束**：只记录已验证事实（功能验证 pass 用例 / blocked 已确认根因 / 用户在用例设计或执行中确认），不记录推测。

> 不要手工填充推测内容；让 pass 的用例与用户确认逐步沉淀事实。
